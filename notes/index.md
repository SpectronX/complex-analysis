## Complex Analysis: visuals and code, all in one place

This is a collection of notes on complex analysis, with a focus on visualizing concepts and providing code assistance to generate those visuals. 

I find mathematical concepts quite interesting when you can see them in action and that's what motivated me to create this collection. This is a work in progress, and I will be adding more content over time.

The goal is to provide a resource that is both educational and practical, allowing you to not only learn the theory but also get your hands dirty with code to see the concepts come to life. 

If you have any suggestions or feedback on how to improve this collection, please feel free to reach out. I belive this can be a great resource for anyone interested in complex analysis.

### The tool

Currently in development is `cpxmath`, a small Python package that includes an interactive conformal mapping visualizer. All you have to do is type in a function, and watch how the complex plane is mapped. 

*Note:* While there are other packages that can do this, and even better, I wanted to create a simple one that is easy to use, and also understand what goes into making packages in Python.
