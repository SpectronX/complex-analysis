Cauchy-Riemann Equations

The Cauchy-Riemann equations are a set of two partial differential equations that provide a necessary condition for a complex function to be differentiable at a point, $z_0 = (x_0, y_0)$. If $f(z) = u(x, y) + iv(x, y)$, where $u$ and $v$ are real-valued functions of two real variables $x$ and $y$, then the Cauchy-Riemann equations are given by: $$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}.$$
